# 🌐 Personal Portfolio

A modern responsive portfolio built using React, Node.js, Express, MongoDB, and Docker.

## 🚀 Live Demo

### Frontend
https://portfolio-client-g2jn.onrender.com

### Backend API
https://portfolio-1070.onrender.com

## 🛠️ Tech Stack

- React (Vite)
- Node.js
- Express.js
- MongoDB Atlas
- Docker
- Render
- Git & GitHub

## ✨ Features

- Responsive Design
- Dark/Light Theme
- Projects Section
- Skills Section
- Contact Form
- MongoDB Database Integration

## 📂 Installation

### Clone the repository

```bash
git clone https://github.com/TandelVishwa/portfolio.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
